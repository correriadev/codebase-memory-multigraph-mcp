# Referência de segurança

O processo de divulgação, escopo e canais herdados estão em [SECURITY.md](../SECURITY.md). Esta pasta não estabelece compromissos adicionais de prazo, CVE ou atendimento em nome do mantenedor do fork.

Operações locais de registro, exclusão de índice e promoção podem alterar estado. As verificações de autoridade das tools normativas têm escopo nos handlers; [hooks](feature/mutation_gate.md) não constituem um sandbox universal. Para configuração de tokens e caminhos, consulte [configuração](CONFIGURATION.md) e [limites de temas](feature/tradition.md).
