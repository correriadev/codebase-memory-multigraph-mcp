# Project Digest

## ARCHITECTURE SUMMARY
- **Pattern**: Layered architecture with MCP JSON-RPC protocol server, Multi-Graph Federation, and SQLite WAL storage.
- **Layers**: Transport/MCP (`src/mcp/`), Federation & Admission (`src/admission/`), Query & Merge (`src/query/`), Core (`src/core/`), Persistence & Daemons (`src/daemon/`, `src/store/`, `src/db/`).
- **Key Constraints**:
  - REQUIRED: Pool-managed SQLite handle acquisition with LRU eviction (max 16 open FDs).
  - REQUIRED: Cycle-pruned graph traversal with 64-bit FNV-1a VisitedSet (max depth 5).
  - REQUIRED: Two-tier anchor verification before admitting horizon changes to Base Graph.
  - FORBIDDEN: Direct unmanaged SQLite handle creation outside `HorizonConnectionPool`.
  - FORBIDDEN: Unbounded recursive graph traversal without `VisitedSet`.

## TESTING SUMMARY
- **Frameworks**: C11 custom test harness (`Makefile.cbm`) with ASan/UBSan, pytest for Python integration.
- **Commands**:
  - `make -f Makefile.cbm test-foundation` — fast foundation C unit tests.
  - `make -f Makefile.cbm test` — full C test suite including federation.
  - `make -f Makefile.cbm test-tsan` — thread sanitizer build.
  - `pytest tests/test_multi_graph_federation.py` — Python federation regression suite.
- **Coverage Thresholds**: Core 90%, Federation/Admission 90%, Query 85%, Global 80%.
