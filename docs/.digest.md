# Project Digest

## ARCHITECTURE SUMMARY
- **Pattern**: Layered C11 MCP stdio server (35 tools), Multi-Graph Federation, Cognitive Respiration Seam, and SQLite WAL.
- **Layers**: MCP (`src/mcp/`), Union & Gate (`src/union/`), Admission (`src/admission/`), Query (`src/query/`), Core (`src/core/`), Pipeline (`src/pipeline/`), Store (`src/store/`).
- **Key Constraints**:
  - REQUIRED: Pool-managed SQLite handle acquisition with LRU eviction (max 64 open FDs).
  - REQUIRED: Two-tier Tree-sitter anchor verification with relocation before admitting changes.
  - REQUIRED: Two-Phase Reconciled promotion order: base_db COMMIT first, horizon status update second.
  - REQUIRED: Fail-fast consolidation validation on every SQLite prepare and step call.
  - REQUIRED: Reverse causal BFS traversal for transitive recall, ignoring non-causal edges.
  - REQUIRED: PreToolUse mutation seam; repository writes require active session with intent scope.
  - FORBIDDEN: Direct unmanaged SQLite handle creation outside `HorizonConnectionPool`.
  - FORBIDDEN: Promoting horizons with active blocking contestations or generation drift.
  - FORBIDDEN: Mutating horizon status before base database transaction commit.

## TESTING SUMMARY
- **Frameworks**: C11 custom test harness (`Makefile.cbm`), `test-runner`, Python unittest/pytest.
- **Commands**:
  - `./build/c/test-runner anchor_checker recall_engine` — 33 native C unit/integration tests.
  - `python -m unittest discover tests` — complete 186-test Python regression suite.
  - `python -m unittest tests/test_ast_anchor_isolation.py` — F001 AST anchor isolation suite.
  - `python -m unittest tests/test_atomic_admission_concurrency.py` — F002 atomic admission suite.
  - `python -m unittest tests/test_transitive_recall_closure.py` — F003 transitive recall suite.
  - `make -f Makefile.cbm test` — full C test suite under AddressSanitizer and UndefinedBehaviorSanitizer.
- **Coverage Thresholds**: Core 90%, Admission 90%, Union 90%, Query 85%, Gateway 85%, Global 80%.
