# CBM-MGH: orientação rápida

## IMPLEMENTAÇÃO

Servidor MCP nativo C/SQLite/Tree-sitter, com daemon, grafo persistente e UI opcional. Há 45 tools verificadas: 17 herdadas e 28 exclusivas frente ao ref local upstream/main. Fontes e runtime comparados em 2026-10-21; checkout 8dd9f4ec com alterações locais.

## USO E LIMITES

Grafo básico dispensa sessões, skills experimentais e hooks. Horizontes são overlays especulativos; promoção modifica o grafo, não implementa código. Catálogo temático versionado e regras locais do harness usam mecanismos distintos. Hooks estritos são opt-in por CBM_ENFORCE_MUTATION_GATE=1 e exigem registro no cliente.

Há lacunas entre schemas e handlers, sobretudo credenciais normativas, anchors e manifests. Recall interno tem testes e implementação, mas nenhuma chamada de produção localizada. Nem disponibilidade das tools nem validação estrutural dos docs demonstram redução de alucinações.

## TESTES

Runner C: make -f Makefile.cbm test. Foco: make -f Makefile.cbm test-focused TEST_SUITES="union_session union_theme_registry harness_v2". Windows: scripts/test-windows.ps1. Sanitizers dependem da toolchain. Não há percentual mínimo de coverage demonstrado nesta revisão. A suíte integral não foi reexecutada para esta revisão documental.

Checkpoint de 26/10/2026: orquestrador TS em implementação, 30 testes locais aprovados e smoke de leitura do MCP instalado aprovado. Testes C selecionados: 50 passes e 3 falhas; integração completa com Codex/CBM reais e S0 ainda pendentes. Consulte a Spec 010 pela topologia documental.
