# CBM cognitive boundary skills

These skills define universal procedures for Track B. Their premise comes from `docs/PRD/novos-paradgimas/PRD_V3.md`: a project knows what it does and intends, while external Tradition supplies craft guidance that can be cited, contested, and versioned.

## Three territories and their authorities

| Territory | Question | Authority |
| --- | --- | --- |
| Project Realization | What exists? | Code and execution evidence. |
| Project Idealization | What is intended, and why? | Claims, decisions, and operator validation. |
| External Tradition | How is the craft practiced? | Versioned thematic graphs and their curators. |

Tradition is not a third plane inside the project. The project holds references to it. A `DEVE` binding is normative; a `PODE` relation is advisory. Both require operator validation. A project session may read themes but must not write to them. When project intent conflicts with a bound standard, surface a contestation for the operator to resolve.

## Use

1. `graph-grounding` classifies the activity and consults the project planes first. For specialty production, it then consults applicable Tradition.
2. `horizon-deliberator` develops provisional possibilities. Each craft judgment cites verifiable canon or declares invention with a reason.
3. `adversarial-traverser` contests claims with evidence and checks provenance, deviations, and territory boundaries.
4. `union-tracer` reconciles closure with observable facts. `refusal-discipline` guides responses to refusals throughout the work.
5. `skill-contract-attestor` checks that a skill defines a procedure while domain standards remain in themes.

`constellation-individuator` and `level-graduator` remain deferred. The first prepares evidence-backed proposals; the second prepares non-regression evidence. Neither can admit or supersede skills through the current CBM interface.

## Current implementation boundary

These files guide agents; they do not install skills into a client or create missing APIs. The current interface does not provide a complete binding query, every Idealization claim type, public contract registration, or a trace with references for every judgment. Mark those gaps as unresolved. An agent report is not a host-admitted record.
