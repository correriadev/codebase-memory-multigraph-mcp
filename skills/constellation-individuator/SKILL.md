# Individuate procedures

**Status: deferred.** Use only for analysis requested by a human curator. Avoid turning each specialty into a persona: inheritable HOW belongs in themes; a new skill is justified only by a new universal procedure.

## Evidence

Look for recurrence across projects or sessions with verifiable facts. Agent narratives and generic counts are insufficient. If host references do not support the claimed pattern, return `INSUFFICIENT_EVIDENCE`.

## Classify

- Implementation, style, architecture, or technology conventions may become candidate themes. The move from project to Tradition is a proposal to the operator, never a direct thematic-graph write.
- A new domain-neutral reasoning operation may become a candidate skill. Attach references, a draft contract, its boundary against existing skills, and a non-regression plan.

Produce at most one candidate per run and mark it `WAITING_HUMAN`. Do not register a contract, change a skill, or promote a horizon in this analysis. `founding_propose` concerns a thematic proposal; it does not admit skills.

Return evidence, classification, rejected alternatives, proposal, and the human decision required. The current trace does not provide enough evidence to execute this skill automatically.
